`vibe99ctl` now ships with every install: the `.deb` links it to `/usr/bin/vibe99ctl`, the AppImage embeds it (reach it via `--appimage-extract` or `vibe99ctl install-cli`), and Windows falls back to `vibe99ctl install-cli`, which copies the CLI to `~/.local/bin` and adds that directory to the user PATH. Linux/Windows CI artifacts and GitHub Releases now include the bare `vibe99ctl` binary, and `vibe99ctl --version` always matches the app version.
